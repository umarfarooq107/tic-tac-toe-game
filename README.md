# Tic Tac Toe Game 🎮

A fully functional **Tic Tac Toe game** built with **vanilla JavaScript**, focusing on clean logic, DOM manipulation, and responsive UI design.  
This project demonstrates my ability to translate game rules into efficient JavaScript logic while maintaining readable and scalable code.

## 🔍 What This Project Demonstrates
- Strong understanding of **JavaScript fundamentals**
- DOM manipulation and event handling
- Game state management
- Conditional logic and edge-case handling
- Clean, maintainable front-end code
- UI/UX basics with responsive design

## 🚀 Features
- Two-player gameplay (X vs O)
- Automatic win and draw detection
- Interactive UI with instant feedback
- Game reset functionality
- No external libraries or frameworks

## 🛠️ Tech Stack
- **HTML5** – Structure
- **CSS3** – Styling & layout
- **JavaScript (ES6)** – Game logic & interactivity

## 📂 Project Structure
├── index.html # Game structure
├── style.css # Styling and layout
└── script.js # Game logic and interactions

## 🎯 How the Game Works
- Players take turns clicking on the grid.
- The game tracks moves and updates the UI dynamically.
- Winning combinations are checked after each move.
- Displays winner or draw result instantly.
